## Frozen decisions
- Direction: Option 3 — Premium & Distinctive.
- Primary identity: Adeni symbol + Adeni wordmark.
- Tagline is secondary and optional: BEAUTY • WELLNESS • YOU.
- Purple dot over the final `i` is a distinctive brand accent.
- Carbon Design remains the UI design-system reference; the brand mark is independent of Carbon.

## Canonical colors (digital starting specification)
- Adeni Purple: #7F56FF
- Adeni Purple Deep: #6F42FF
- Adeni Teal: #13C2A3
- Adeni Teal Light: #25D0BC
- Carbon Gray 100 / Brand Ink: #161616
- White: #FFFFFF

These RGB/HEX values are the digital master starting point. CMYK and Pantone equivalents must be proofed by a commercial printer before they are treated as authoritative physical-production colors.

## Logo rules
1. Never redraw the symbol in application code.
2. Never recolor individual components outside approved variants.
3. Do not stretch, rotate, skew, shadow, or outline the logo.
4. The tagline must not be treated as an inseparable part of the core trademark.
5. Use the mark-only version for very small sizes.
6. Preserve clear space around the logo equal to at least 25% of the mark height.

## Important production note
The `Adeni-Mark-*.svg` files in this package are true vector path artwork.

The wordmark lockups are a **production candidate**, not yet the final trademark filing artwork: the selected Option 3 wordmark originated in generated raster concept art, so its exact custom letterforms do not exist as authoritative vector paths yet. These lockups intentionally preserve editable/live type as a placeholder rather than pretending an auto-trace is a legally exact master.

Before trademark filing, permanent signage, or large print procurement, a designer/vector specialist should:
- reconstruct the Option 3 wordmark letterforms as paths;
- visually compare them against the approved reference at high magnification;
- convert the final lettering to outlines;
- proof CMYK/Pantone output;
- return the outlined SVG/PDF/EPS as the legal/print master.

The symbol itself can already be used as scalable vector artwork.
