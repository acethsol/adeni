# Adeni Option 3 Master Identity Package

This package begins the production reconstruction of the approved Option 3 identity.

The **Adeni symbol is supplied as true vector path artwork** and can scale without pixelation.

The wordmark lockups are intentionally labeled production candidates because the approved Option 3 lettering came from generated raster concept artwork. A genuine trademark master should not be created by pretending an automatic trace is exact. The final wordmark should be manually reconstructed/outlined and visually signed off before trademark filing or permanent physical signage.

See `specification/MASTER_SPEC.md` for the frozen decisions and production checklist.
