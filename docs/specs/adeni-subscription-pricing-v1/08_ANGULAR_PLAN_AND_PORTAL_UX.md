# Angular UX Requirements

## Discover pricing page
Show:
- Starter / Professional / Business
- Professional = Most Popular
- correct country/currency
- 30-day Professional trial
- no permanent free tier

Outcome messaging:
Starter — Get bookable
Professional — Run & grow
Business — Scale operations

## Portal billing page
Show:
- current plan
- billing status
- trial end date
- agreed monthly amount
- currency
- next billing date
- price lock end date if any
- discount/offer summary
- entitlements
- upgrade/downgrade controls when supported

Do not show latest catalog price as if it is the tenant's agreed price.

## Admin billing UI
Show/edit:
- current subscription
- pricing version
- agreed price
- current catalog price for comparison
- trial controls
- custom price
- discounts
- expiry/effective dates
- price lock
- comp reason
- audit history

Require a reason for commercial changes.
