# Discover local configuration

Angular reads **`src/environments/environment.development.ts`** in dev (`angular.json` fileReplacements).

## Public API + dev customer (no Auth0)

Matches Next `DEV_CUSTOMER_AUTH0_SUB` when API `Auth0:Enabled` is `false`:

```typescript
devCustomerAuth0Sub: "auth0|local-customer",
auth0: { domain: "", clientId: "", audience: "https://api.adeni.io" },
apiBaseUrl: "http://localhost:5169",
publicAppUrl: "http://localhost:5190",
```

Bookings and `/my-bookings` work via `X-Dev-Auth0-Sub` on the API.

## Market cookies

Uses the same cookie names as Next (`adeni_market`, `adeni_coords` from `@adeni/shared`):

- `?market=lagos` on any route sets the market cookie (1 year).
- Browser geolocation updates `adeni_coords` (24h) via `app-market-geo-sync`.
- Optional env override: `envMarketId: "lagos"` (mirrors `ADENI_MARKET`).

## Auth0 SPA (staging — register tenant when ready)

Create a **separate Single Page Application** for discover (do not reuse portal/admin clients):

| Setting | Local value |
|---------|-------------|
| Callback URLs | `http://localhost:5190` |
| Logout URLs | `http://localhost:5190` |
| Allowed Web Origins | `http://localhost:5190` |

```typescript
devCustomerAuth0Sub: "",
auth0: {
  domain: "your-tenant.auth0.com",
  clientId: "<discover-spa-client-id>",
  audience: "https://api.adeni.io",
},
```

Enable JWT validation when testing end-to-end: `Auth0:Enabled: true` on the API.

## Run

```bash
npm run dev:discover
# http://localhost:5190
```
