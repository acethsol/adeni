# Portal local configuration

Angular reads **`src/environments/environment.development.ts`** in dev (see `angular.json` fileReplacements).

## Local API + dev business sub (no Auth0)

Matches Next.js `DEV_BUSINESS_AUTH0_SUB` when API `Auth0:Enabled` is `false`:

```typescript
devBusinessAuth0Sub: "auth0|local-business",
auth0: { domain: "", clientId: "", audience: "https://api.adeni.io" },
apiBaseUrl: "http://localhost:5169",
```

## Auth0 SPA (PKCE)

**Registration can wait until staging/Azure** — leave `auth0.domain` / `clientId` empty locally and use `devBusinessAuth0Sub` with API `Auth0:Enabled: false`.

When ready, create a **Single Page Application** in Auth0 (separate from the Next.js Regular Web app):

| Setting | Local value |
|---------|-------------|
| Callback URLs | `http://localhost:5173` |
| Logout URLs | `http://localhost:5173` |
| Allowed Web Origins | `http://localhost:5173` |

```typescript
devBusinessAuth0Sub: "",
auth0: {
  domain: "your-tenant.auth0.com",
  clientId: "<spa-client-id>",
  audience: "https://api.adeni.io",
},
```

Enable API JWT validation when testing end-to-end:

`src/Adeni.Api/appsettings.Development.json` → `"Auth0": { "Enabled": true }`

CORS already allows `http://localhost:5173` in Development.

## Run

```bash
npm run dev:portal
# http://localhost:5173
```

Production builds use `baseHref: /business/` for strangler routing behind the same host as discover.
